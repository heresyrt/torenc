# 실제 콘텐츠·확대 갤러리 구현 계획

> **에이전트 작업자용:** `superpowers:executing-plans`를 사용해 체크박스 순서대로 실행한다.

**목표:** 실제 사업·시공·인증 콘텐츠와 확대 가능한 미디어 갤러리를 구현한다.

**구조:** 타입이 지정된 데이터에서 모든 항목과 자산을 제공하고, 서버 섹션은 카드 목록을 렌더링하며 클라이언트 갤러리 컴포넌트만 모달 상태를 관리한다. 원본 PDF와 고해상도 미리보기를 함께 제공한다.

**기술 스택:** Next.js, TypeScript, Tailwind CSS, Next Image, React, Vitest, Testing Library, Poppler

## 작업 1: 자산 준비와 타입·데이터

- [ ] 원본을 보존한 채 사업 6종, 시공 5종 사진을 영문 파일명으로 복사한다.
- [ ] 인증 PDF 3종을 영문 파일명으로 복사하고 200dpi PNG 미리보기를 생성한다.
- [ ] 실패 테스트에 실제 회사 소개, 주소, 사업 6종, 실적 5종, 인증 3종을 명시한다.
- [ ] 타입과 데이터를 실제 문구·자산 경로로 교체해 테스트를 통과시킨다.

## 작업 2: 확대 모달

- [ ] 열기·닫기, 포커스 복귀, 확대·축소, 이전·다음, 키보드 조작의 실패 테스트를 작성한다.
- [ ] `GalleryMedia`와 `MediaLightbox`를 최소 구현한다.
- [ ] 확대 범위 50~250%, 스크롤 잠금, PDF 열기·다운로드를 구현한다.
- [ ] 모달 테스트를 통과시킨다.

## 작업 3: 실제 섹션 연결

- [ ] 페이지 테스트에 사업·실적·인증의 실제 제목과 항목 수를 추가한다.
- [ ] 6개 사업 카드, 5개 시공 카드, 3개 인증 카드를 공통 갤러리에 연결한다.
- [ ] 임시 수치와 가짜 설명을 제거하고 실제 회사 소개와 주소를 반영한다.
- [ ] 반응형 카드 및 모달 스타일을 완성한다.

## 작업 4: 문서와 최종 검증

- [ ] README에 콘텐츠·이미지·PDF 교체 위치와 갤러리 조작법을 기록한다.
- [ ] 전체 테스트, ESLint, 타입 검사, 프로덕션 빌드를 실행한다.
- [ ] 데스크톱과 모바일에서 카드, 확대·축소, 키보드, 가로 넘침, 콘솔 오류를 확인한다.
