# Kakao Map Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static location placeholder with an interactive Kakao map that works after adding one JavaScript key.

**Architecture:** A focused client-side SDK loader owns script deduplication and Kakao global typing. A `KakaoMap` client component owns address geocoding, map overlays, user-visible state, and the directions link; the existing server-rendered `Location` section only passes typed company data.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, Kakao Maps JavaScript SDK, Vitest, Testing Library

## Global Constraints

- The only required setting is `NEXT_PUBLIC_KAKAO_MAP_APP_KEY`, containing a Kakao Developers JavaScript key.
- Company name and address remain sourced from `src/data/site-data.ts`.
- Do not commit a real API key, REST API key, or admin key.
- Load the SDK once with `autoload=false&libraries=services`.
- Preserve a readable address and Korean fallback UI whenever configuration, SDK loading, or geocoding fails.
- Keep the existing responsive Location section layout.
- Completion requires Vitest, ESLint, TypeScript, and a production Next.js build to pass.

- [ ] **Step 3: Define the SDK surface and implement the loader**

Declare only the Kakao constructors and methods used by this feature: `Map`, `LatLng`, `Marker`, `InfoWindow`, `services.Geocoder`, `services.Status.OK`, and `maps.load`. Implement a module-level Promise, reuse an existing `script[data-kakao-map-sdk]`, reject on load failure, and call `window.kakao.maps.load` after the script loads.

```ts
let kakaoMapPromise: Promise<KakaoMapsApi> | null = null;

export function loadKakaoMapSdk(appKey: string) {
  if (kakaoMapPromise) return kakaoMapPromise;
  kakaoMapPromise = new Promise((resolve, reject) => {
    const script = document.createElement("script");
    script.dataset.kakaoMapSdk = "true";
    script.src = `https://dapi.kakao.com/v2/maps/sdk.js?appkey=${encodeURIComponent(appKey)}&autoload=false&libraries=services`;
    script.onload = () => window.kakao.maps.load(() => resolve(window.kakao.maps));
    script.onerror = () => reject(new Error("카카오맵 SDK를 불러오지 못했습니다."));
    document.head.appendChild(script);
  });
  return kakaoMapPromise;
}
```
