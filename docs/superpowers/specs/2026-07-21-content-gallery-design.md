# 실제 콘텐츠·확대 갤러리 설계 명세

## 목표

기존 임시 콘텐츠를 `torenc.com`에 게시된 실제 회사 소개, 사업 분야, 시공 실적, 인증현황 콘텐츠로 교체한다. 사용자가 제공한 `tmp/image`의 원본 사진과 PDF를 웹 자산으로 준비하고, 모든 자료를 상세히 확인할 수 있는 접근성 높은 확대 모달을 제공한다.

## 콘텐츠 원칙

- 회사 소개와 사업 분야 설명은 현재 `torenc.com` 공개 문구를 그대로 사용한다.
- 사업 분야는 TOR 자립식 옹벽, 절토부옹벽, 보강토 옹벽, 중력식 옹벽, 경관 옹벽, 산석 옹벽 6종이다.
- 시공 실적은 로컬에 실제 사진이 존재하는 거제 상동2지구, 정읍 내장산리조트, 곤지암 한씨주어종중, 공주 월송, 평택 가재지구 5개 현장으로 구성한다.
- 인증현황은 제공된 디자인등록증 2종과 특허증 1종으로 구성한다.
- 임의로 만든 성과 수치, 프로젝트 설명, 인증 명칭은 제거한다.
- 실제 주소는 `경기도 남양주시 다산순환로 20, 2층 B-C-02-019호 (다산동, 현대프리미어캠퍼스)`로 교체한다.

## 자산 처리

원본 `tmp/image`는 수정하거나 이동하지 않는다. 사업 사진은 `public/images/business`, 시공 사진은 `public/images/projects`, 인증 미리보기는 `public/images/certificates`, 원본 PDF는 `public/documents/certificates`에 영문 케밥 표기 파일명으로 복사한다.

사진은 원본 해상도를 유지한다. 브라우저 표시에는 Next Image 품질 90, 정확한 `sizes`, 고정 비율, 지연 로딩을 적용한다. PDF는 첫 페이지를 200dpi PNG로 렌더링해 작은 글자도 확대 시 읽을 수 있도록 하고, 원본 PDF 링크를 별도로 제공한다.

## 확대 모달

사업, 시공, 인증 카드의 미디어를 버튼으로 만들어 클릭 또는 Enter/Space로 연다. 모달은 현재 항목의 제목과 전체 이미지를 표시하고 다음 기능을 제공한다.

- 닫기, 이전, 다음
- 50%부터 250%까지 확대·축소 및 100% 초기화
- 확대 이미지 영역 스크롤
- `Escape`, 좌우 방향키, `+`, `-`, `0` 키 지원
- 배경 스크롤 잠금
- 모달 제목 연결, 포커스 이동 및 닫힌 뒤 실행 버튼으로 포커스 복귀
- 인증 항목의 원본 PDF 새 창 열기와 다운로드

모바일에서도 버튼이 겹치지 않고 이미지 영역을 손가락으로 스크롤할 수 있어야 한다.

## 구성 요소

- `GalleryMedia`: 카드 미디어와 확대 버튼
- `MediaLightbox`: 공통 모달, 순서 이동, 확대 상태와 키보드 이벤트
- `Business`, `Projects`, `Certificates`: 동일한 갤러리 계약으로 실제 데이터를 렌더링
- `site-data.ts`: 실제 공개 문구와 자산 메타데이터의 단일 출처

## 검증

테스트는 실제 항목 수와 문구, 이미지 경로, 모달 열기·닫기, 이전·다음, 확대 한계, PDF 링크를 확인한다. 완료 조건은 전체 테스트, ESLint, 타입 검사, 프로덕션 빌드 통과와 데스크톱·모바일 브라우저 시각 검증이다.
