# 투명 헤더 로고 수정 설계

## 문제와 원인

`logo-horizontal-dark.png`는 배경이 불투명한 `#2c3f4f` 이미지다. 헤더에는 같은 기본색에 95% 투명도와 배경 블러가 적용되어 있어, 밝은 본문 위로 스크롤하면 헤더의 실제 합성색이 달라지고 로고의 사각 배경이 드러난다.

## 승인된 해결 방식

- 기존 로고의 네이비 배경을 알파 채널로 변환한 `logo-horizontal-transparent.png`를 생성한다.
- 헤더는 `#2c3f4f` 불투명 배경으로 표시하고 불필요한 배경 블러를 제거한다.
- 헤더와 푸터 모두 투명 로고 파일을 사용해 어느 배경에서도 로고 주변 사각형이 생기지 않게 한다.
- 로고의 흰색과 골드 요소, 표시 크기, 링크와 대체 텍스트는 유지한다.

## 검증

- 컴포넌트 테스트로 헤더와 푸터가 투명 로고 파일을 사용하는지 확인한다.
- 로고 파일에 실제 알파 채널이 있는지 확인한다.
- 테스트, 린트, 타입 검사와 프로덕션 빌드를 수행한다.
- 밝은 본문까지 스크롤한 모바일 화면을 브라우저로 확인한다.
