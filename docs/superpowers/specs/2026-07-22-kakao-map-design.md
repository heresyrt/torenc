# 카카오맵 오시는 길 연동 설계

## 목표

현재 오시는 길 섹션의 정적 지도 대체 화면을 카카오맵으로 교체한다. 운영자는 카카오 Developers에서 발급한 JavaScript 키 하나만 `.env.local`에 입력하면 지도가 동작해야 한다. 회사 주소와 이름은 기존 `site-data.ts`를 단일 데이터 원본으로 유지한다.

## 사용자 경험

오시는 길 섹션에는 회사 주소를 중심으로 한 카카오맵을 표시한다. 사용자는 지도를 드래그하거나 확대·축소할 수 있고, 회사 위치의 마커와 `더오름 이앤씨` 정보창을 즉시 확인할 수 있다. 지도 위 또는 인접한 명확한 링크를 누르면 카카오맵 길찾기 화면으로 이동한다.

작은 화면에서도 기존 오시는 길 정보와 지도 배치를 유지하며, 지도 조작 영역과 길찾기 링크는 터치하기 충분한 크기로 제공한다.

## 기술 구조

`MapPlaceholder`를 카카오맵 전용 클라이언트 컴포넌트로 교체한다. 오시는 길 서버 컴포넌트는 기존처럼 `siteData.contact` 값을 전달하며, 지도 컴포넌트가 브라우저에서 SDK 로딩과 지도 생성을 담당한다.

카카오 JavaScript SDK는 `autoload=false`와 `libraries=services` 옵션으로 한 번만 동적 로딩한다. 모듈 수준의 공유 Promise를 사용해 React 개발 모드의 재실행이나 컴포넌트 재마운트에서도 스크립트 태그와 초기화가 중복되지 않게 한다.

SDK 로드가 끝나면 주소 검색 서비스로 `siteData.contact.address`를 좌표로 변환한다. 성공한 좌표로 지도 중심과 마커를 설정하고 회사명 정보창을 연다. 따라서 주소 변경 시 위도와 경도를 별도로 관리하지 않는다.

## 설정

공개 환경변수 이름은 `NEXT_PUBLIC_KAKAO_MAP_APP_KEY`로 고정한다. 여기에는 카카오 Developers 애플리케이션의 JavaScript 키를 입력한다. 저장소에는 실제 키를 커밋하지 않고 `.env.example`에 빈 예시만 제공한다.

README에는 다음 내용을 안내한다.

- 카카오 Developers에서 애플리케이션 생성
- 카카오맵 사용 설정 및 JavaScript 키 확인
- 개발 주소와 운영 도메인을 JavaScript SDK 플랫폼에 등록
- `.env.local`에 키 입력 후 개발 서버 재시작

## 데이터 흐름

1. `Location`이 회사명과 주소를 지도 컴포넌트에 전달한다.
2. 지도 컴포넌트가 환경변수의 JavaScript 키를 확인한다.
3. SDK를 동적 로드하고 주소 검색 라이브러리를 초기화한다.
4. 주소를 좌표로 변환한다.
5. 지도, 마커, 회사명 정보창을 생성한다.
6. 길찾기 링크는 검색된 좌표와 회사명을 카카오맵 URL에 포함한다.

## 오류 및 대체 동작

키가 없으면 빈 지도 영역을 남기지 않고 설정이 필요하다는 한국어 안내와 회사 주소를 표시한다. SDK 네트워크 로딩 실패, 허용 도메인 오류, 주소 검색 실패도 동일한 레이아웃의 대체 화면으로 처리하되 원인을 구분할 수 있는 문구를 제공한다.

오류가 발생해도 사용자는 주소를 읽고 복사할 수 있어야 한다. 컴포넌트가 언마운트되거나 입력 주소가 바뀌면 이전 지도 인스턴스의 후속 상태 변경을 막는다.

## 접근성과 보안

지도 컨테이너에는 회사 위치를 설명하는 접근성 레이블을 제공한다. 길찾기 링크는 키보드 포커스가 분명하고 새 창으로 열릴 경우 이를 보조 텍스트로 알린다. 지도 SDK 키는 브라우저에서 사용되는 공개 식별자이므로 HTTP 리퍼러 기반 도메인 등록을 필수 운영 절차로 문서화한다.

실제 키, REST API 키, 관리자 키는 저장소에 포함하지 않는다.

## 테스트 및 검증

구현 전에 테스트를 추가하고 예상한 이유로 실패하는 것을 확인한다. 테스트 범위는 다음과 같다.

- 키가 없을 때 설정 안내와 주소 표시
- SDK 로딩 중 상태 표시
- SDK 및 주소 검색 성공 시 지도 초기화, 마커, 정보창, 길찾기 링크 생성
- SDK 로딩 실패와 주소 검색 실패 시 대체 화면
- 같은 SDK 스크립트를 중복 삽입하지 않는 동작

완료 조건은 Vitest 전체 테스트, ESLint, TypeScript 타입 검사, Next.js 프로덕션 빌드가 모두 성공하는 것이다. 가능한 경우 실제 JavaScript 키를 넣은 개발 화면에서 데스크톱과 모바일 지도 크기, 마커 위치, 정보창, 길찾기 링크도 확인한다.

## 범위 제외

- 현재 위치 권한 요청과 현재 위치 기반 경로 계산
- 여러 지점 또는 마커 관리
- 서버 측 REST 주소 검색
- 교통수단별 자체 경로 표시
- 실제 운영용 카카오 JavaScript 키 등록
