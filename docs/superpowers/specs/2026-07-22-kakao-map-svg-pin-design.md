# 카카오맵 SVG 위치 핀 설계

## 목표

현재 CSS 도형으로 조합한 회사 위치 핀을 매끄러운 SVG 물방울형 핀으로 교체한다. 책갈피나 집처럼 보이는 각진 형태를 제거하고 지도 위에서 작고 정돈된 위치 표시를 제공한다.

## 시각 디자인

핀은 24×32px 크기의 단일 SVG로 렌더링한다. 외곽은 부드럽게 이어지는 물방울 실루엣이며 브랜드 골드로 채우고 얇은 흰색 테두리와 작은 그림자를 적용한다. 내부에는 작은 흰색 원을 중앙보다 조금 위에 둔다.

회사명 라벨은 기존 네이비 배경과 흰색 글자를 유지하되 글자와 여백을 한 단계 줄여 핀보다 과도하게 커 보이지 않도록 한다. 라벨과 핀은 하나의 카카오 `CustomOverlay`로 회사 좌표에 고정한다.

## 구현 방식

외부 이미지 파일이나 원격 URL을 사용하지 않는다. `document.createElementNS`로 SVG, path, circle 요소를 만들고 고정된 벡터 경로를 설정한다. 회사명은 기존처럼 `textContent`로 삽입해 HTML 문자열 주입 가능성을 만들지 않는다.

기존 주소 검색, 지도 레벨 `4`, 오류 안내, 지도 드래그·확대·축소 동작은 변경하지 않는다.

## 테스트 및 검증

- 기존 CSS 꼬리 요소가 생성되지 않음
- `data-company-map-pin` 요소가 SVG이며 `viewBox="0 0 24 32"`를 가짐
- SVG에 골드 물방울 path와 흰색 중심 circle이 존재함
- 회사명 라벨이 계속 렌더링됨
- 집중 테스트와 전체 테스트, ESLint, TypeScript, 프로덕션 빌드 통과
- 실제 지도에서 핀이 매끄러운 물방울형으로 보이고 줌 이후에도 좌표에 유지됨

## 범위 제외

- 회사 좌표, 지도 범위, 주소 검색 방식 변경
- 회사명 라벨 제거
- 별도 이미지 자산 또는 애니메이션 추가
