# 카카오맵 시각 정리 설계

## 목표

오시는 길 지도에서 중복 정보와 불필요한 행동 요소를 제거하고, 회사 위치 핀을 더 작고 정돈된 형태로 바꾸며, 첫 화면에 더 넓은 주변 지역이 보이도록 한다.

## 정상 상태

지도 로딩과 주소 검색이 성공하면 지도 위에는 회사 위치를 나타내는 커스텀 오버레이만 표시한다. 기존 주소 카드와 `카카오맵에서 길찾기` 링크는 렌더링하지 않는다. 주소와 연락처는 지도 왼쪽의 오시는 길 정보 영역에서만 제공한다.

## 오류 상태

환경변수 누락, SDK 로딩 실패, 주소 검색 실패 시에는 현재처럼 한국어 오류 안내와 주소를 표시한다. 정상 상태에서는 이 안내 카드 전체를 숨긴다.

## 회사 위치 핀

브랜드 네이비와 골드 색상은 유지한다. 현재 지름 40px의 원형 핀은 약 28px 너비의 세로로 긴 물방울형 핀으로 교체한다. 흰색 중심점과 작은 그림자를 사용하고, 회사명 라벨은 핀 위에 유지한다. 핀과 라벨은 하나의 `CustomOverlay`로 좌표에 고정한다.

## 지도 범위

초기 지도 레벨을 `3`에서 `4`로 변경한다. 카카오맵에서 더 큰 레벨은 더 넓은 지역을 표시하므로 현재보다 한 단계 멀리 보인다. 사용자는 이후 드래그와 확대·축소로 원하는 범위를 조절할 수 있다.

## 테스트 및 검증

- 정상 상태에서 주소 카드와 길찾기 링크가 표시되지 않음
- 오류 상태에서는 안내와 주소가 유지됨
- 지도 생성 옵션의 초기 레벨이 `4`임
- 커스텀 오버레이에 작은 물방울형 핀과 회사명 라벨이 포함됨
- Vitest 전체 테스트, ESLint, TypeScript, 프로덕션 빌드 통과
- 실제 카카오 JavaScript 키가 설정된 브라우저에서 핀 크기와 지도 범위 확인

## 범위 제외

- 카카오 지도 자체의 장소명·아이콘 표시 정책 변경
- 줌 애니메이션 중 카카오 SDK 내부 타일·오버레이 재렌더링 변경
- 별도 길찾기 모달 또는 외부 지도 링크
