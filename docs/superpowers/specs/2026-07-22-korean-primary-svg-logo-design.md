# 한글 중심 SVG 로고 교체 설계

## 목표

사이트의 영문 중심 가로형 로고를 AI 원본에 포함된 한글 중심 가로형 로고로 교체한다. 한글 회사명 `(주)더오름 이앤씨`를 크게 표시하고, 영문 `The Oreum E&C Co.,Ltd`는 작은 보조 문구로 둔다.

## 승인된 해결 방식

- AI 원본의 어두운 배경용 한글 중심 가로형과 세로형 시안을 벡터 경로가 유지되는 투명 SVG로 추출한다.
- SVG의 여백은 실제 로고 외곽에 맞춰 정리하고 원본의 골드, 흰색 색상과 비율을 보존한다.
- 헤더는 캐시 충돌을 피하도록 어두운 배경 전용 파일명으로 분리한 가로형 SVG를 사용하고, 푸터는 세로형 SVG를 사용한다.
- 헤더 표시 폭은 기본 화면에서 `240px`, `sm` 이상에서 `280px`로 표시한다.
- 푸터는 기본 화면에서 `280px`, `sm` 이상에서 `320px`, `lg` 이상에서 `360px`로 표시한다.
- 기존 PNG 로고와 심볼 자산은 호환 및 향후 사용을 위해 삭제하지 않는다. 앱 아이콘과 심볼 사용처도 변경하지 않는다.

## 접근성과 호환성

- 기존 홈 링크와 회사명 기반 대체 텍스트를 유지한다.
- SVG는 브라우저에서 외부 이미지로 안전하게 표시할 수 있는 정적 자산으로 저장한다.
- 로고의 고유 종횡비를 유지해 화면 크기에 따라 찌그러지거나 잘리지 않게 한다.

## 검증

- 컴포넌트 테스트에서 헤더와 푸터가 새 SVG를 참조하는지 확인한다.
- SVG의 `viewBox`, 투명 배경, 경로 기반 벡터 여부를 확인한다.
- 테스트, 린트, 타입 검사와 프로덕션 빌드를 수행한다.
- 데스크톱과 모바일에서 헤더·푸터의 크기, 정렬, 잘림 여부를 시각적으로 확인한다.
