# 모바일 확대 뷰어 포커스 표시 설계

## 목표

모바일에서 이미지 확대 뷰어를 열었을 때 우상단 `닫기` 버튼이 이미 선택된 것처럼 금색 포커스 테두리를 표시하는 현상을 제거한다. 닫기 버튼 자체와 접근성 포커스 관리는 유지한다.

## 원인

확대 뷰어가 열리면 화면 크기나 입력 방식과 관계없이 `닫기` 버튼에 프로그래밍 방식으로 포커스를 이동한다. 모바일 브라우저도 이 포커스를 `:focus-visible`로 표시해 버튼 주변에 금색 테두리가 나타난다.

## 동작 설계

- 모바일 화면에서는 확대 뷰어 컨테이너에 포커스를 이동한다.
- 뷰어 컨테이너는 프로그래밍 방식으로만 포커스할 수 있게 하고 시각적 외곽선은 표시하지 않는다.
- 데스크톱 화면에서는 기존처럼 `닫기` 버튼에 포커스를 이동한다.
- `닫기` 버튼의 렌더링, 터치 동작, 키보드 탭 포커스 스타일은 변경하지 않는다.
- Escape 닫기, 좌우 키 이동, 뷰어를 닫은 뒤 원래 갤러리 카드로 포커스를 돌려주는 동작을 유지한다.

## 구현 범위

`ContentGallery`에 확대 뷰어 컨테이너 참조를 추가하고, 뷰어가 열린 시점의 반응형 조건에 따라 모바일 컨테이너 또는 데스크톱 닫기 버튼을 포커스한다. 현재 데스크톱 UI가 전환되는 `md` 기준과 동일한 화면 폭을 사용한다.

## 테스트

- 모바일 화면 폭에서 확대 뷰어를 열면 뷰어 컨테이너가 포커스를 받고 `닫기` 버튼은 포커스를 받지 않는지 확인한다.
- 데스크톱 화면 폭에서는 기존처럼 `닫기` 버튼이 포커스를 받는지 확인한다.
- 닫기 버튼 클릭, Escape 닫기, 닫은 뒤 원래 카드 포커스 복귀 테스트를 유지한다.

## 제외 범위

- 닫기 버튼의 제거 또는 위치·색상·크기 변경
- 확대·축소, 이동, 스와이프 동작 변경
- 전역 `focus-ring` 스타일 변경
