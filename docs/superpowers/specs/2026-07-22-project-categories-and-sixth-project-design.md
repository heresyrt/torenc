# 시공실적 공법 분류 및 6번째 현장 추가 설계

## 목표

시공실적 카드 5개를 6개로 확장하고, 모든 카드에 반복 표시되던 `시공실적` 문구를 사진에서 확인되는 공법명으로 교체한다. 사용자가 새로 제공한 정읍 내장산 리조트 사진으로 기존 공개 이미지를 교체하고, 화성 석포리 현장을 새 카드로 추가한다.

## 표시 방식

기존 카드 구조와 골드색 메타 텍스트 위치를 유지한다. 별도 필터나 이미지 위 배지는 추가하지 않는다. 카드 이미지 아래 첫 줄에 공법명을 표시해 사진을 가리지 않으면서 현장 성격을 빠르게 파악할 수 있게 한다. 공법명은 기존 `text-xs`에서 `text-sm`으로 한 단계 키워 가독성을 높인다.

## 정렬 순서

프로젝트는 공법 기준으로 `TOR 자립식 옹벽 → 절토부옹벽 → 보강토 옹벽 → 산석 옹벽` 순서로 묶는다. 같은 공법 안에서는 기존 등록 순서를 유지한다. 이에 따른 카드 순서는 거제 상동2지구, 정읍 내장산 리조트, 화성 석포리, 곤지암 한씨주어종중, 공주 월송, 평택 가재지구 순이다.

## 현장 및 공법 분류

1. 거제 상동2지구 현장 — `TOR 자립식 옹벽`
2. 정읍 내장산 리조트 현장 — `절토부옹벽`
3. 곤지암 한씨주어종중 현장 — `보강토 옹벽`
4. 공주 월송 현장 — `보강토 옹벽`
5. 평택 가재지구 자연석(산석)옹벽 — `산석 옹벽`
6. 화성 석포리 현장 — `절토부옹벽`

분류명은 사이트의 사업 분야 명칭과 맞춰 표기한다. 화성 석포리는 원지반 보강과 PC 패널 표면보호공이 드러나는 사진을 기준으로 절토부옹벽으로 분류한다.

## 이미지와 데이터 변경

- `tmp/image/시공실적/정읍 내장산 리조트 현장.jpg`를 공개 프로젝트 이미지 경로의 기존 정읍 이미지에 덮어쓴다.
- `tmp/image/시공실적/화성 석포리 현장.jpeg`를 웹에 적합한 영문 파일명으로 `public/images/projects`에 추가한다.
- 사이트 데이터에 화성 석포리 현장 정보를 추가하고 프로젝트 수를 6개로 조정한다.
- 각 프로젝트의 `meta` 값을 위 공법명으로 변경한다.

## 레이아웃과 반응형 동작

현재 시공실적 갤러리는 모바일 1열, 태블릿 이상 2열이므로 6개가 모든 주요 화면에서 균형 있게 배치된다. 기존 확대 보기, 좌우 이동, 썸네일 동작은 새 항목을 자동으로 포함하며 별도 UI 변경은 필요하지 않다.

## 검증

- 데이터 테스트에서 프로젝트 수가 6개인지 확인한다.
- 여섯 카드의 공법명이 비어 있지 않고 `시공실적`이라는 일반 문구가 남지 않았는지 확인한다.
- 정읍 및 화성 이미지 파일과 선언된 이미지 크기가 일치하는지 확인한다.
- 전체 테스트, 린트 및 프로덕션 빌드를 실행한다.
