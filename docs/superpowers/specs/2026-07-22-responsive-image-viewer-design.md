# 반응형 이미지 뷰어 설계

## 목표

현재 전체 화면 갤러리를 PC와 모바일의 입력 방식에 맞게 개선한다. PC에서는 썸네일과 좌우 화살표로 사진을 전환하고 확대·축소·화면 맞춤 및 마우스 드래그 이동을 제공한다. 모바일에서는 뷰어 UI를 고정한 채 사진에만 핀치 확대·축소와 확대 사진 이동을 적용한다.

## 공통 상태와 원칙

- 갤러리는 현재 항목 인덱스, 확대 배율, 이미지 이동 좌표를 관리한다.
- 배율은 화면 맞춤 상태인 `1`부터 최대 `3`까지 제한한다.
- 새 사진으로 전환하거나 화면 맞춤을 실행하면 배율을 `1`, 이동 좌표를 중앙인 `(0, 0)`으로 초기화한다.
- 축소 결과가 `1`에 도달하면 이동 좌표도 `(0, 0)`으로 초기화한다.
- 이동 좌표는 확대된 이미지가 뷰포트를 벗어나 빈 영역을 과도하게 노출하지 않도록 현재 배율과 표시 크기에 따라 제한한다.
- 항목이 하나뿐이면 전환 컨트롤을 숨기거나 비활성화하고 현재 사진을 유지한다.

## PC 인터랙션

- 이미지 좌우에 이전·다음 화살표를 표시하며 목록의 양 끝에서는 순환 이동한다.
- 이미지 아래에는 모든 항목의 썸네일을 표시한다. 현재 항목은 강조 테두리와 접근성 상태로 구분하며 썸네일을 선택하면 해당 사진으로 이동한다.
- 조작 버튼은 축소, 확대, 화면 맞춤의 세 가지로 제한한다. 이미지 위치로 본문을 이동하는 버튼은 제공하지 않는다.
- 확대와 축소는 고정 단계로 배율을 조절하고 최소·최대 배율에 도달한 버튼은 비활성화한다.
- 배율이 `1`보다 클 때 이미지에서 마우스 왼쪽 버튼을 누른 채 드래그하면 이미지 위치가 이동한다.
- 배율이 `1`일 때는 드래그 이동을 시작하지 않으며 커서도 이동 가능 상태로 표시하지 않는다.
- `ArrowLeft`, `ArrowRight`, `Escape` 키보드 조작은 유지한다.

## 모바일 인터랙션

- 제목, 순서, 닫기, PDF 링크 등 기존 뷰어 UI는 고정하며 이미지 요소에만 확대·이동 변환을 적용한다.
- 두 손가락 간격 변화를 사용해 사진을 핀치 확대·축소한다. 핀치 중심점을 기준으로 이동 좌표를 보정해 보고 있던 지점이 자연스럽게 유지되도록 한다.
- 배율이 `1`일 때 한 손가락 수평 스와이프는 이전·다음 사진 전환으로 처리한다. 짧거나 수직 성분이 더 큰 제스처는 전환하지 않는다.
- 배율이 `1`보다 클 때 한 손가락 드래그는 확대 사진 이동으로 처리하고 사진 전환은 실행하지 않는다.
- 멀티터치가 감지된 제스처는 사진 전환으로 판정하지 않는다.
- 포인터가 취소되거나 이미지 영역을 벗어나 종료되면 진행 중인 이동 상태를 안전하게 해제한다.

## 렌더링과 구성

- 기존 `ContentGallery`의 카드, 포털 모달, 순환 인덱스, 포커스 복귀, 배경 스크롤 잠금 구조를 유지한다.
- 확대·이동 로직은 배율과 좌표를 입력받아 제한된 다음 상태를 반환하는 작은 순수 함수로 분리해 테스트 가능하게 한다.
- 마우스와 터치는 가능한 범위에서 Pointer Events로 통합하되, 두 손가락 거리 계산에는 활성 포인터 집합을 사용한다.
- 이미지 변환에는 `transform: translate(...) scale(...)`을 사용하고 UI 컨트롤은 변환 컨테이너 밖에 둔다.
- 썸네일 목록은 항목이 많아져도 가로 스크롤할 수 있으며 선택된 썸네일이 보이도록 한다.
- PC 전용 컨트롤은 데스크톱 브레이크포인트에서 노출하고 모바일에서는 핀치·스와이프 중심의 현재 UI를 유지한다.

## 접근성과 오류 처리

- 모든 버튼은 `축소`, `확대`, `화면 맞춤`, `이전 이미지`, `다음 이미지`, 항목별 썸네일 이름을 제공한다.
- 현재 썸네일에는 `aria-current`를 제공한다.
- 최소·최대 배율에서는 해당 확대 버튼의 비활성 상태를 보조 기술에도 전달한다.
- 모달이 열리면 닫기 버튼으로 포커스를 이동하고 닫으면 원래 카드를 실행한 버튼으로 복귀한다.
- 이미지 변경 후에도 모달의 제목, 대체 텍스트, 현재 순서, 인증서 PDF 링크가 현재 항목과 함께 갱신된다.
- `Escape` 닫기와 배경 스크롤 잠금 복원은 입력 도중에도 정상 동작해야 한다.

## 테스트와 완료 조건

- PC 컨트롤과 썸네일이 렌더링되고 이전·다음 및 임의 썸네일 선택으로 현재 항목이 변경되는지 테스트한다.
- 확대·축소가 `1`에서 `3` 사이로 제한되고 화면 맞춤이 배율과 위치를 초기화하는지 테스트한다.
- 확대 상태의 마우스 드래그가 이미지를 이동하며 기본 배율에서는 이동하지 않는지 테스트한다.
- 모바일 기본 배율의 한 손가락 스와이프는 사진을 전환하고 확대 상태의 한 손가락 드래그는 사진만 이동하는지 테스트한다.
- 핀치가 UI가 아닌 이미지 배율만 변경하고, 멀티터치가 사진 전환을 발생시키지 않는지 테스트한다.
- 사진 전환 시 확대 배율과 위치가 초기화되는지 테스트한다.
- 기존 키보드 이동, 닫기와 포커스 복귀, PDF 링크 동작의 회귀 테스트를 유지한다.
- 관련 컴포넌트 테스트, 전체 테스트, ESLint, 타입 검사와 프로덕션 빌드가 통과해야 한다.
- 실제 PC 브라우저에서 버튼·화살표·썸네일·마우스 드래그를, 모바일 크기에서 핀치·스와이프·확대 사진 이동과 UI 고정을 확인한다.
