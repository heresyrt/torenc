# 사업분야 상세 페이지 설계

## 목표

홈페이지의 여섯 사업분야 카드를 개별 상세 페이지로 연결해, 기존 `https://torenc.com/buField1`부터 `buField6`에 있는 공법 설명과 설치·제품 정보를 더 읽기 좋은 형태로 제공한다. 전달받은 `tmp/image/사업분야_디테일/`의 사진으로 기존 저해상도 이미지를 교체한다.

## URL 및 탐색

- 상세 URL은 의미 있는 영문 경로를 사용한다.
  - `/business/tor-self-supporting-wall`
  - `/business/cut-slope-wall`
  - `/business/reinforced-soil-wall`
  - `/business/gravity-wall`
  - `/business/landscape-wall`
  - `/business/natural-stone-wall`
- 홈페이지 사업 카드 전체를 상세 페이지 링크로 바꾸고, 카드에 `상세 보기` 행동을 표시한다.
- 상세 페이지의 상단에는 홈페이지로 돌아가는 경로와 현재 공법명을 표시하고, 하단에는 이전·다음 사업분야 및 전체 목록으로 돌아가는 링크를 둔다.

## 상세 화면 UX

각 상세 페이지는 다음 순서로 구성한다.

1. 공법 번호와 제목, 기존 사이트의 설명 원문을 줄 단위로 보여주는 소개 영역
2. 해당 공법의 고해상도 대표 사진
3. `설치 순서` 섹션: 모바일 1열, 태블릿 2열, 데스크톱 3열의 번호 카드. 각 카드는 공정명과 전달받은 사진을 사용한다.
4. 공정 사진은 클릭하면 기존 갤러리의 전체화면 이미지 보기·확대·스와이프 동작을 그대로 사용한다.

경관 옹벽은 기존 사이트의 `경관 옹벽 종류`를 유지한다. 설치 순서 대신 조경용·조경/토목용·토목용·보차도 블록을 분류한 제품 갤러리를 표시한다.

영상은 이번 범위에서 완전히 제외한다. mp4 파일은 복사·배포하지 않고, 영상 영역이나 재생 UI도 만들지 않는다.

## 콘텐츠 및 이미지

- 모든 공법 소개 문구와 공정명은 기존 `buField1`~`buField6`의 한국어 원문을 사용한다.
- 이미지 원본은 `tmp/image/사업분야_디테일/`에서 선정하고, 웹 배포용 영문 파일명으로 `public/images/business/` 아래에 복사한다.
- 기존 페이지의 저해상도 대표 이미지와 설치 이미지 대신 전달받은 사진을 쓴다.
- 제품 이미지처럼 원본 종횡비가 다양한 경우 카드 영역은 균일하게 유지하고 `object-contain`으로 잘림을 방지한다. 현장 공정 사진은 `object-cover`를 사용한다.
- 이미지의 실제 픽셀 크기를 데이터에 기록하여 CLS 없이 렌더링한다.

## 데이터와 컴포넌트 경계

- `site-data.ts`는 사업 카드 정보, 상세 URL, 소개 문단, 단계/제품 이미지 메타데이터를 한 곳에서 관리한다.
- 새로운 상세 페이지 컴포넌트는 URL 매개변수로 하나의 사업 데이터를 읽어 소개·갤러리를 렌더링한다.
- 기존 `ContentGallery`는 상세 이미지 항목의 전체화면 보기 동작을 재사용하되, 필요한 표시 모드만 명시적으로 추가한다.
- 유효하지 않은 상세 URL은 Next.js 404 화면을 반환한다.

## SEO·접근성

- 각 상세 페이지는 공법명을 포함한 고유 title, description, canonical URL을 생성한다.
- 대표·공정·제품 사진에 의미 있는 한국어 대체 텍스트를 제공한다.
- 카드형 링크와 전체화면 보기 컨트롤은 키보드로 접근 가능해야 한다.

## 검증

- 데이터 테스트에서 여섯 상세 slug, 단계/제품 데이터, 영상 파일 부재를 확인한다.
- 페이지 테스트에서 각 유효 slug의 제목·소개·설치 순서 또는 제품 갤러리를 확인하고, 알 수 없는 slug는 404 처리를 확인한다.
- 기존 갤러리의 전체화면 동작 테스트를 유지한다.
- lint, typecheck, 전체 테스트와 정적 export 빌드를 실행한다.

## 범위 제외

- mp4 동영상의 게시·변환·플레이어 UI
- 기존 `buField1`~`buField6` 주소에 대한 리다이렉트
- 관리자 기능, 문의 폼, 데이터베이스
